# Практическая работа № 2 — калькулятор выражений на WPF

Учебное настольное приложение на C# и WPF. Пользователь вводит арифметическое выражение, а отдельная библиотека разбирает его и вычисляет результат. Такое разделение оставляет алгоритм независимым от оконного интерфейса и позволяет проверять его модульными тестами.

## Возможности

- сложение, вычитание, умножение и деление;
- возведение в степень оператором `^`;
- круглые скобки и вложенные выражения;
- десятичные числа с точкой или запятой;
- унарные знаки `+` и `-`;
- обработка пробелов, некорректного ввода и деления на ноль;
- ввод с экранной клавиатуры и поддержка клавиш приложения.

Примеры выражений: `2 + 3 * 4`, `(2 + 3) * 4`, `2^3^2`, `-2^2`, `1,5 + 2`.

## Архитектура

Решение состоит из трёх проектов, каждый отвечает за отдельную часть:

```text
KoshechkinCalculator.sln
├── KoshechkinCalculatorApp/       # WPF-окно и обработка пользовательского ввода
├── KoshechkinCalculatorLib/      # вычислительный движок
├── KoshechkinCalculatorTests/    # модульные тесты библиотеки
├── README.md
└── Report.pdf                    # сопроводительная записка
```

`KoshechkinCalculatorApp` преобразует нажатия кнопок в текст выражения и показывает результат или понятное сообщение об ошибке. `KoshechkinCalculatorLib` не зависит от WPF: его публичный метод `CalculatorEngine.Evaluate` получает строку и возвращает число. `KoshechkinCalculatorTests` проверяет библиотеку напрямую, не создавая окно приложения.

## Как разбирается выражение

Движок использует рекурсивный спуск. Уровни разбора отражают приоритет операций: выражение обрабатывает `+` и `-`, терм — `*` и `/`, далее разбираются унарный знак, степень и первичные значения (число или выражение в скобках). Остаток строки проверяется после разбора, чтобы незамеченные символы приводили к ошибке формата.

Степень связывается справа: например, `2^3^2` трактуется как `2^(3^2)`. Унарный знак обрабатывается отдельно от степени, поэтому `-2^2` вычисляется как `-(2^2)`. Перед возвратом результата движок проверяет, что значение конечно.

## Проверки

Набор MSTest покрывает обычные арифметические операции и приоритет, скобки, десятичную запятую, унарный минус, правую ассоциативность степени, деление на ноль, незакрытую скобку и неожиданный символ. Параметризованный тест проверяет несколько корректных выражений одним набором входных данных.

## Требования

- Windows 10/11;
- Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений .NET»;
- .NET 8 SDK и Windows Desktop Runtime.

## Открытие, сборка и запуск

Откройте `KoshechkinCalculator.sln` в Visual Studio и запустите проект `KoshechkinCalculatorApp`. Команды из каталога репозитория:

```powershell
dotnet build KoshechkinCalculator.sln
dotnet test KoshechkinCalculatorTests/KoshechkinCalculatorTests.csproj
dotnet run --project KoshechkinCalculatorApp/KoshechkinCalculatorApp.csproj
```

В приложении выражение можно набрать кнопками или клавиатурой. Кнопка `AC` очищает поле, `=` выполняет вычисление. Неверный формат и деление на ноль обрабатываются отдельно от успешного результата.
